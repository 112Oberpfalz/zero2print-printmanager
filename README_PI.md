# Zero2Print PrintManager auf Raspberry Pi

Diese Anleitung richtet den Zero2Print PrintManager auf einem Raspberry Pi ein.

## Empfohlenes Setup

- Raspberry Pi 4 oder 5
- Raspberry Pi OS Lite 64-bit
- LAN-Verbindung
- 64 GB microSD oder USB-SSD
- Feste IP über FritzBox

## 1. Raspberry Pi vorbereiten

Raspberry Pi OS Lite 64-bit flashen.

Empfohlene Einstellungen im Raspberry Pi Imager:

```text
Hostname:
zero2print

SSH:
aktivieren

Benutzer:
pi oder eigener Benutzer

WLAN:
optional, besser LAN
